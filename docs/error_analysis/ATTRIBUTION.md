# Dataset and image attribution

The representative images in this package are from **SID_Set** (`saberzl/SID_Set`) and are included solely to document model errors for the Reality Check hackathon submission.

- Dataset: https://huggingface.co/datasets/saberzl/SID_Set
- Dataset licence stated on the dataset card: CC BY 4.0
- Authentic SID_Set images originate from OpenImages V7 according to the supplied manifest.
- Preserve the dataset citation and any original-source attribution required by SID_Set/OpenImages when publishing these images.

The quantitative evaluation also uses CIFAKE and a leakage-safe WildFake slice. This package does not redistribute their raw images.
