# Reality Check — Submission Error Analysis

This folder contains the submission-ready material for Deliverable 5.

- `ERROR_ANALYSIS_NOTE.md`: detailed GitHub/technical report.
- `DEVPOST_ERROR_ANALYSIS_NOTE.md`: concise text suitable for Devpost.
- `REPRESENTATIVE_ERROR_GALLERY.html`: visual false-positive/false-negative gallery.
- `REPRESENTATIVE_ERRORS.csv`: image scores and qualitative observations.
- `ROBUSTNESS_CONDITION_SUMMARY.csv`: clean and per-transformation metrics.
- `TRANSFORMATION_FLIP_SUMMARY.csv`: new errors caused by each transformation.
- `ATTRIBUTION.md`: dataset/image attribution and publication caution.
- `assets/`: the eight representative SID_Set images used in the gallery.

Open the HTML gallery locally in a browser. Copy the Markdown note into the public repository and retain the attribution file if the representative images are published.
